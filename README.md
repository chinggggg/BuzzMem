# BuzzMem：記憶體小幫手

**BuzzMem: Memory Helper**

住在 Mac 選單列的記憶體小幫手。一個數字告訴你記憶體夠不夠用，一句白話告訴你該怎麼做。

A memory helper that lives in your Mac menu bar. One number tells you if your Mac has enough memory, and one plain tip tells you what to do about it.

## 下載 Download

到 [Releases](https://github.com/chinggggg/BuzzMem/releases/latest) 下載最新的 `BuzzMem-x.x.x.dmg`，打開後把 BuzzMem 拖到「應用程式」資料夾。

Download the latest `BuzzMem-x.x.x.dmg` from [Releases](https://github.com/chinggggg/BuzzMem/releases/latest), open it, and drag BuzzMem into Applications.

- macOS 26 或更新版本，支援 Apple 晶片和 Intel 的 Mac
- 已通過 Apple 公證，可以直接打開
- macOS 26 or later, Apple silicon and Intel
- Notarized by Apple

## 完整版和 App Store 版 Full edition vs. App Store

這裡下載的是**完整版**，比 App Store 版多了這些功能：

- 最忙的 App、最佔記憶體的 App 排行
- 釋放記憶體
- 刪除 App 後找出殘留檔
- 管理開機自動執行的項目
- 異常提醒

This is the **full edition**. Compared with the App Store version, it adds Top CPU and Top Memory lists, Free up memory, leftover file cleanup after uninstalling apps, startup item management, and unusual activity alerts.
